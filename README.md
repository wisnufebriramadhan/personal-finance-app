# Personal Finance App — Dompetku

Dompetku adalah aplikasi Flutter untuk pencatatan keuangan pribadi dengan budget bulanan, saldo Cash/E-Wallet/Bank, pengeluaran real-time, analisis sederhana, dan backup data lokal.

## Fitur utama

- Budget bulanan dan indikator sisa budget.
- Pencatatan pengeluaran dengan kategori dan sumber pembayaran.
- Saldo Cash, E-Wallet, serta Bank yang diperbarui secara real-time.
- Riwayat transaksi, konfirmasi hapus, dan analisis berdasarkan kategori.
- Backup dan pemulihan data melalui file JSON.
- Floating bottom navigation dan pengalaman mobile-first.

## Menjalankan aplikasi

```bash
flutter pub get
flutter run
```
